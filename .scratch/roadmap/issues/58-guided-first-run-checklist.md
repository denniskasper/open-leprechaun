# 58 — Guided first-run checklist

**What to build:** A checklist that walks the Admin from an empty database to a first tax report, where every item's state is derived from real data rather than from a flag someone dismissed.

**Blocked by:** 39, 25

**Status:** ready-for-agent

- [ ] The checklist covers: set a password, enable two-factor, add Platforms and Accounts, connect or import, reconcile, resolve blockers, generate a report
- [ ] Each item's done state is derived from real data, never from a dismissible flag
- [ ] Each undone item links to the screen that completes it
- [ ] Every empty state across the app explains what to do next
- [ ] Every error names the thing that failed and the action that fixes it
