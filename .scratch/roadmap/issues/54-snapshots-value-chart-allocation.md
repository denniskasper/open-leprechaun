# 54 — Snapshots, value chart and allocation

**What to build:** The Admin can see how the portfolio has developed, without a deposit reading as a gain.

**Blocked by:** 20, 42

**Status:** ready-for-agent

- [ ] Portfolio snapshots are taken on a schedule and stored
- [ ] A value chart covers selectable ranges, backed by snapshots plus current live value
- [ ] The chart distinguishes value change from contributions and withdrawals
- [ ] Allocation charts cover asset class, Instrument and Platform
- [ ] Each chart states how many positions it charts against how many are held
- [ ] Positions below a threshold are grouped rather than dropped
- [ ] Realised and unrealised results are shown separately
- [ ] A figure that cannot be computed says so rather than showing zero
